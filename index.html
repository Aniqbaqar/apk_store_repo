Android apps, one tap to download.

Pick an app, download the APK and install it on your phone. Files are checked before they are listed.

How to install an APK

  1. Download the APK file by tapping the Download button.
  2. Open the file from your notifications or the Downloads folder.
  3. If asked, tap Settings and allow installs from this browser (“Install unknown apps”).
  4. Tap Install, then Open.
